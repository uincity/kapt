# ============================================================
# 12. exclusive_area_sqm 데이터 타입 검사
# ============================================================

전용면적은 Decimal 기준으로 검사한다.

binary float 비교를 사용하지 않는다.

검사:

- 숫자로 변환 가능한지
- 0보다 큰지
- 비정상적으로 큰 값 없는지
- 불필요한 과도한 precision 변형이 없는지

이상치는 WARNING으로 출력한다.

예:

exclusive_area_sqm <= 0
→ FAIL

exclusive_area_sqm > 400
→ WARNING 후 원자료 확인

8. Master와 excluded/pending 중복 허용
