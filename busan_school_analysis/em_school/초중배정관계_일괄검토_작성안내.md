# 초·중 배정관계 일괄검토 CSV 작성안내

대상 파일: `초중배정관계_일괄검토_2026.csv`

## 수정 방법

수정할 관계만 `수정적용`을 `Y`로 바꾼다. `초등학교ID`, `중학교ID`, 현재관계와 원문·출처 열은 수정하지 않는다.

선택한 행에는 다음 다섯 열을 모두 작성한다.

- `수정관계유형`: 확정 배정 / 배정 가능 / 조건부 배정 / 학교군 포함 / 미확정
- `수정반영상태`: 점수 반영 / 해당 없음으로 제외 / 학교 미확정으로 제외 / 타 교육지원청 미확정
- `실제배정비율`: 확인된 실제 비율만 입력한다. 추정하거나 후보 수로 나눈 비율을 입력하지 않는다.
- `수정근거`: 판단 내용을 구체적으로 작성한다.
- `근거자료`: 교육지원청 문서명, 기준연도, 페이지 또는 확인 가능한 실제 배정자료명을 작성한다.

## 확정배정 예시

한 초등학교의 모든 학생이 한 중학교로 배정되는 것이 확인된 경우:

```text
실제 중학교 행
수정적용=Y
수정관계유형=확정 배정
수정반영상태=점수 반영
실제배정비율=1.0

나머지 후보 중학교 행
수정적용=Y
수정관계유형=배정 가능
수정반영상태=해당 없음으로 제외
실제배정비율=0.0
```

한 초등학교에 활성 `확정 배정`을 두 개 이상 둘 수 없다. 확정배정과 다른 활성 후보를 동시에 둘 수도 없다.

현재 용소초에는 과거 override로 `EXACT/ACTIVE/0.5`가 두 건 남아 있어 `검토메모`에 오류가 표시된다. 실제로 대천중·남천중이 조건에 따라 나뉘는 관계라면 두 행을 `조건부 배정/점수 반영`으로 고쳐야 한다. 한 학교만 100% 배정된다면 해당 행만 `확정 배정/점수 반영/1.0`으로 두고 나머지 후보를 제외해야 한다.

## 조건부 관계

성별, 주소, 추첨 또는 학교군 배정에 따라 중학교가 달라지면 `확정 배정`으로 입력하지 않는다. 조건이 문서에 명시된 경우 `조건부 배정`, 후보만 확인된 경우 `배정 가능`을 사용한다.

## 수정 불가능 행

`수정가능=N`은 중학교 공식 ID가 아직 해소되지 않은 관계다. 이 CSV로 가져올 수 없으며 먼저 학교 식별 검토가 필요하다.

## 가져오기

수정한 CSV를 프로젝트에 저장한 뒤 먼저 검증만 하려면 `--rebuild` 없이 실행한다. 검증 성공 시 override CSV가 갱신되고 기존 파일은 시각이 포함된 backup으로 보존된다.

```powershell
python main.py import-relation-review --csv "수정한 CSV 경로"
```

Phase 7까지 다시 계산하려면 다음을 사용한다.

```powershell
python main.py import-relation-review --csv "수정한 CSV 경로" --rebuild
```

이후 Phase 11 분석을 갱신한다.

```powershell
python main.py phase11-build
python main.py phase115-build
```
